# v16.1 Tables Tab Implementation Plan

> **For agentic workers:** executed inline with superpowers:executing-plans (this project works without subagents).

**Goal:** the Tables tab of `docs/superpowers/specs/2026-09-18-v16-1-tables-tab-design.md`.

**Architecture:** a pure `TableStore` (split, serialise, edit, paste, rename)
with no TUI dependency; `TuiState` owns one beside the text buffer and always
compiles `joined()`; `TuiInput`/`TuiRender` gain a `View::Tables`.

**Global constraints:** engine and `.des` format unchanged; baselines and
regression byte-identical; every TUI test keeps passing (adjusted only where
the tab order or palette changed); commits end with the Co-Authored-By line.

### Task 1: TableStore
Files: create `include/TableStore.hpp`, `src/TableStore.cpp`; CMake (des_ui);
tests in `tests/v16_tests.cpp`.
Interfaces:
```cpp
enum class TableKind { Variable, Array, Matrix, Schedule };
struct Table { TableKind kind; std::string name, note, timeUnits{"Hours"};
               std::size_t rows{1}, columns{1};
               std::vector<std::string> cells; };   // row-major; Schedule: columns == 2
struct SplitResult { std::string modelText; std::vector<Table> tables; };
SplitResult splitTables(const std::string& fileText);
std::string tablesSection(const std::vector<Table>& tables);   // "" when none
std::string joinTables(const std::string& modelText, const std::vector<Table>& tables);
std::vector<std::vector<std::string>> parsePastedBlock(const std::string& text);
bool isNumberCell(const std::string& s);
std::string renameInText(const std::string& text, const std::string& from, const std::string& to);
std::vector<std::string> usersOf(const ModelDocument& doc, const std::string& name);
const char* kindName(TableKind);
```
Tests: ride_hailing split gives 6 tables with the right shapes and model text
without any `[Variable]`/`[Schedule]`; join → split → join is byte-identical;
compile(joined) of ride_hailing has the same named statistics after 2 reps as
the original file; paste of tab/comma/space blocks; renameInText whole words
only (`Num_CV` not in `Num_CVX`); notes survive.

### Task 2: TuiState owns the tables
`TuiState` gains `const std::vector<Table>& tables()`, `joinedText()`; `open`,
`fromText` split; `save` writes joined; `reparse` reads joined; diagnostics
past the model's last line are mapped to tables (`tableDiagnostics()`); the
Model palette drops Variable/Schedule/ScheduleRow; `View::Tables`, ^D.
Existing tests that save or compare `buffer().text()` keep their meaning
because the buffer is the model text.

### Task 3: the tab's state and keys
Focus (Kinds/Editor/List), selected kind, selected table, editor cursor
(header field index or cell row/col), cell/field edit draft, create, resize
(with Confirm when dropping values), insert/delete row, paste, rename (Confirm
to update references), delete (Confirm), own undo/redo stack of
`std::vector<Table>` snapshots, `?` help, mouse.

### Task 4: rendering
Three panels, grid with row/column headers and scrolling, the used-by line,
error markers, tab label with error count, hints and key map.

### Task 5: docs and gates
README (TUI section), CHANGELOG `[16.1.0]`, manual (new types/members),
V16_READLOG section, package README; suite, baseline, regress, verify,
package.
